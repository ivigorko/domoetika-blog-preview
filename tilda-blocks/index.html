Tilda Zero Block

11 Zero-блоков статьи «Ремонт в новостройке»

Каждый файл = один Zero Block. Открываешь, копируешь содержимое целиком, вставляешь в Tilda. Картинки (assets/*.jpg) заменить на URL из Tilda Library.

  1. 01_head_css_jsonldHEAD — CSS + JSON-LD (вставить перед /head)
  2. 02_headerHEADER — topbar
  3. 03_heroHERO — большой заголовок
  4. 04_toc_leadTOC + LEAD + первая картинка
  5. 05_osobennostiSECTION 1 — Особенности ремонта
  6. 06_startSECTION 2 — С чего начать
  7. 07_etapySECTION 3 — Этапы ремонта
  8. 08_oshibkiSECTION 4 — Типичные ошибки
  9. 09_checklist_faqSECTION 5 + 6 + Disclaimer (Чек-лист + FAQ + дисклеймер)
  10. 10_ctaCTA — форма заявки
  11. 11_footerFOOTER — реквизиты

Порядок вставки в Tilda: 01 (в head) → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 → 11.

Лимит одного Zero Block: 242,14 КБ. Самый большой здесь — 09_checklist_faq (~12 КБ), запас 20×.

Где брать картинки: assets/hero.jpg, assets/finish.jpg, assets/osobennosti.jpg, assets/etapy.jpg — залить в Tilda Library, заменить src.
